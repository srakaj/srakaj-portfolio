# srakaj.com portfolio

A lightweight static portfolio for Saranda Rakaj, focused on Legal Engineering, Legal Operations, Privacy and AI.

## Structure

- `index.html` — homepage
- `work.html` — project index
- `about.html` — professional profile
- `projects/` — individual case studies
- `assets/style.css` — site styling
- `assets/main.js` — tiny shared script

## Before publishing

1. Replace the placeholder LinkedIn and GitHub links in `index.html`.
2. Review the email address.
3. Add a PDF CV if you want a downloadable CV link.
4. Review case-study wording for confidentiality.
5. If you publish code repositories, make sure they contain no credentials, internal URLs, production data, or confidential company information.

## Local preview

You can simply open `index.html` in a browser.

For a cleaner local server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.
